This MCP server requires a Linkup API key.

1. Create a free Linkup account at [app.linkup.so](https://app.linkup.so)
2. Copy the API key from your dashboard
3. Set it as `linkup_api_key` below

The server provides `linkup-search` (real-time web search with citable sources) and `linkup-fetch` (fetch a URL as clean markdown), plus `linkup-research` / `linkup-get-research` for long-running research tasks.
